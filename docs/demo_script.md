# 3-Minute Hackathon Demo Script

### 0:00 — Problem

"Hospital records are not one story. They are many linked tables. CareLens AI reconstructs those records into a source-verifiable timeline without turning structured codes into fake clinical notes."

### 0:30 — Timeline

Open Patient Timeline → choose a subject.

"Every event keeps its timestamp and provenance. A judge can trace this event back to its table, field and identifier."

### 1:10 — Evidence retrieval

Ask:
- "creatinine lab"
- "antibiotic medication"
- "ICU observation"

"AI is used for local evidence retrieval. It does not generate a clinical recommendation."

### 1:50 — Abstention

Ask:
"quantum banana spacecraft"

"The model refuses to answer because the record does not support the query. In this challenge, abstention is a feature, not a failure."

### 2:10 — Data quality

Open Data Quality.

"Researchers can see missing timestamps, duplicate source keys and table coverage. These are data-quality flags, not clinical findings."

### 2:35 — Safety

"The prototype is research-only. It cannot diagnose, treat, triage, or make emergency decisions. Patient-level data stay local."

### 2:50 — Honest limitation

"The supplied demo is only 100 patients, so this project does not claim clinical effectiveness or generalizability. Our evaluation is transparent about that."
